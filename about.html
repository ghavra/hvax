What BidEyes does

Estimators upload drawings, specifications and addenda. BidEyes surfaces potential scope gaps and conflicts, such as a mismatch between a drawing and a spec section, each with a citation to the source page, so the estimator can check it before the bid goes out.

How AI is used

BidEyes uses the Claude API from Anthropic to extract evidence and draft findings. It does not replace estimating judgment, code review or contractual advice. It can miss items and can flag things that turn out not to be issues, so every finding is meant for an estimator to verify.
